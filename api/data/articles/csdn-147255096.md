# **第1章 Goodbye World**

---

李程的工位像一座被数据流淹没的孤岛。

三块显示屏的冷光映照着他那张典型的程序员脸——稀疏的头发倔强地梳成「地中海支援边疆」的造型，眼袋浮肿得像两个没优化好的内存泄漏，鼻梁上架着一副镜片比啤酒瓶底还厚的黑框眼镜，镜腿还用透明胶带缠了两圈。

他身上的格子衬衫已经洗得发白，领口处还沾着去年程序员节团建时溅上的火锅油渍。袖口磨得起毛，露出常年敲键盘磨出的老茧——那是二十年如一日和IDE搏斗留下的勋章。

---

「老李，看开点。」隔壁工位的老张递来罐红牛，指了指自己屏幕上正在自动生成的PPT，「连市场部都在用AI了，咱们这波……」

话没说完，部门经理的皮鞋声就从走廊传来。李程条件反射地按下`Alt+Tab`切换屏幕，这个动作熟练得像是刻进了肌肉记忆——就像他右手中指第一个关节因常年按`Ctrl`键而微微变形的弧度一样。

却听见「叮」的一声脆响。所有人手机同时亮起：

**【紧急通知】**

> 即日起启用AI代码审查，连续3日贡献度排名后10%的同事将进入优化名单

李程盯着自己肝了通宵的代码，右下角不知何时多了个血红评分框：

```
[代码审查结果]
相似度检测：35% 疑似手工编写
效率评级：D（建议使用AI重构）
```

「我写的可是核心算法啊……」他攥紧拳头，却看见经理正带着两个穿「AI训练师」工牌的年轻人朝他走来，手里拿着工牌识别器。

---

午夜十二点的办公楼，只剩李程的屏幕还亮着。显示器冷光里，他瞥见玻璃倒影中自己泛红的眼角，和额角刺眼的白发。

「最后再试一次……」他颤抖着敲下：

```java
System.out.println("GoodBye World");
```

突然，左腕上的小米手环发出心率飙到120的警告，随之而来胸口传来尖锐的刺痛。模糊的视野里，屏幕上的代码扭曲成血色文字：

```
[KERNEL PANIC]
错误代码：996-ICU
建议操作：立即休息
```

他想去抓手机，整个人却像被拔掉电源的机器人般栽向键盘。最后的触感是`Ctrl`键硌在脸颊上的冰凉。

---

在意识消散前的最后一刻，李程的眼前闪过走马灯般的画面——这是属于一代码农的史诗：

- **1984年**，刚出生的他就用尿布在摇篮里第一次拼出莫尔斯电码，成功黑进了医院的婴儿监护系统。
- **1992年**，在国际少年宫计算机班，他一战成名，打赢了日本程序猿雷龙，用BASIC语言手写俄罗斯方块，荣获「小比尔盖茨」称号。
- **2002年**，十八岁的他在大学机房连续鏖战72小时，用汇编语言重写了学校教务系统。当教务处主任看着屏幕上自动生成的「全系女生联系方式.txt」时，颤抖着给他颁发了「特长生保研资格」。
- **2008年**，金融危机期间，他单枪匹马用一周时间重构了公司核心系统，成功让老板的奔驰躲过法院查封。从此江湖人称「代码界的及时雨」。
- **2020年**，全球居家办公期间，他创下连续三个月每天工作14小时不猝死的记录，被同事们尊称为「赛博铁人」。体检报告上的「心肌缺血」被他骄傲地裱起来挂在工位：「看，这是福报的勋章！」
- **2023年**，当全公司都在用Copilot自动补全代码时，李程坚持用手写Java，并创下「连续42次编译失败后仍不放弃」的部门记录。同事们在茶水间偷偷叫他「人肉编译器」。
- **2024年**，他负责的核心系统因无法通过AI安全审计被标记为「高危项目」，却因此获得公司颁发的「技术遗产保护奖」。颁奖词写道：「在单元测试覆盖率100%的时代，仍能保持0%覆盖率的定力」。他把奖状贴在工位，旁边是已经泛黄的「心肌缺血」体检报告。
- **2025年**，屏幕蓝光映着工位上「心肌缺血」的体检报告……

---

「——异常数据流接入成功！」

李程猛地睁开眼，发现自己漂浮在无尽的代码星空中。脚下是流动的发光数据流，远处悬浮着巨大的青铜齿轮群，每个齿缝间都跳动着萤火虫般的字符。

视网膜上突然浮现一行行文字：

```
[赛博仙界OS] 启动完毕
内核版本：Cyborg Cultivation 2.6.32
丹田服务器：AWS t2.micro（免费 tier）
境界：码农境
```

「新来的？」一个扎着发光数据辫的少年凭空出现，手中玉简扫过李程全身，突然皱眉：「丹田服务器这么旧？才1核CPU？你这配置连最基础的「踏空而行」都跑不动...」

李程茫然地看着自己半透明的手臂——皮肤下隐约有绿色数据流窜动。

少年见李程一脸茫然，叹了口气：「看来你连基本天道法则都不懂。」他指尖一划，虚空中展开一幅全息投影：

**「此界名曰『云寰』，本是上古程序员证道时崩溃的IDE所化。如今万物皆符，众生修码」**

### ◈ 核心法则

- **算力即灵气**：修士以丹田为本，将冥想所得的算法转化为「算力灵气」，贡献天道，以求突破。
- **天劫即报错**：代码冗余会引发内存泄漏，逻辑死循环直接触发**Kernel Panic天劫**，身死道消。

### **◈ 主宰者**

这是世界的统治者便是**天机阁**，一统天下，管辖所有修士。阁中灵根检测者被称为『清道夫』，淘汰低算力者，掠夺人们的「算力灵气」，来完成宗门的究极飞升...

突然，远处传来齿轮咬合的轰鸣，少年猛地推了李程一把：「是『清道夫』！它们用正扫描你的丹田，被标记为低算力者的修士会被当场**垃圾回收**」

「——发现低算力者——」

（本章完）
