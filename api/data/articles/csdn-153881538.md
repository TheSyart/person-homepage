# 前言

大家作为资深老网民，想必都有过想要拥有自己的 `门户网站`。 <br>或苦于技术领域限制、专业错误 和 没时间的苦恼，大部分兄弟可能没有属于自己的网站。 <br>那么今天 `0基础` 、 `0代码` 、`全流程` 的保姆级教程来了。

# 构想

首先我们自己要对自己的门户网站有个起始的构想，你可能不够专业，那我们就问专业的。 <br>笔者采用的是 `ChatGPT` ，作为全球综合能力最强的AI，还是很令人放心的。
![在这里插入图片描述](/articles/csdn/153881538/image-1.png)

<br>因此，我仅仅给出了自己的身份、技能、需求和想法，其他任由它肆意发挥。 <br>这样我们就得到了一份，对我们门户网站的起始构想，接下来就由 `构想 ——> UI`。

# Mastergo

## 什么是MasterGo？

> `MasterGo` 是一款面向产品设计团队的云端协作平台，集 **AI 智能设计**、**原型制作**、**界面创作** 与 **开发交付** 于一体，提供从构思到落地的全流程、一站式高效协作体验。<br>借助 `AI` 自动生成界面布局、组件样式与交互原型，设计师可快速完成创意探索与高保真设计，显著提升设计效率与协作体验。

# 部署上线

作为一个简单的门户网站 `demo` ,部署上线不要太容易了。 <br>一个轻量级服务器，一个十几块的域名，就可以了。

## 上传代码

> 把我们的代码 `上传` 至指定目录

![在这里插入图片描述](/articles/csdn/153881538/image-7.png)

## 修改配置

> 修改 `nginx` 配置文件: <br>端口、域名或ip 和 路径正确即可。

![在这里插入图片描述](/articles/csdn/153881538/image-8.png)

> 保存完配置文件之后，在命令行中 `检查`、`重载` 一下你配置文件就行了。

![在这里插入图片描述](/articles/csdn/153881538/image-9.png)

```bash
nginx -t # 检查配置是否正确
sudo systemctl reload nginx # 重新加载配置
```
