做开发这几年，我的技术栈从 Java 后端一路扩展到 Vue、Flutter、Python 爬虫。但去年开始，我把大部分业余时间都押在了 AI 上。

## 为什么

**AI 是这个时代给普通人的杠杆。** 两个数据：我的 `claude-agent-examples` 仓库拿到了几百个 star，`emperor-agent` 也有不少人 fork。这些项目的共同点只有一个——把 AI Agent 的开发门槛降到普通人够得着的地方。

我发现大家缺的从来不是模型，而是**怎么把模型用起来**的具体路径。

## 我在做什么

1. **写示例**：从简单的对话 Agent 到复杂的多工具协作，循序渐进地写可运行的例子。
2. **做工具**：把重复的工作封装成开箱即用的项目。
3. **讲出来**：在 B站和抖音用视频讲 AI，让更多人入门。

## 给同样在观望的你

不用等"准备好"才开始。选一个最小的场景，让 AI 帮你完成一件具体的事，然后把它分享出来。

分享 AI，学习 AI，诸君共进步。
