# **2️⃣此时之困境**
在此变革之时，我作为一名侥幸文转理，此前沾沾自喜的民办二本的毕业生，加上我的专业——软件工程（母校已然灭亡的专业🥲），在市场中自然无人问津，但是我：
- 拒绝进厂
- 拒绝销售
- 拒绝外卖

因为我拒绝在黑夜中粉饰太平，不想一辈子碌碌无为，混吃等死，但结局无它，唯失业尔。
恰逢国庆，人声嬉笑，与我何干，只觉熙攘。
人贵有自知之明，大学四年玩的爽，如今自然有苦吃。
我在去年的实习中，才堪堪窥见程序之门，但是纵使亡羊补牢，也难以逾越这天堑。

求职无望，只能希翼自我生存，在咸鱼上尝试做毕设、接相关任务...统统无果。<br>
偶然发现，在这个AI盛世之下，各类工具App，在软件市场中，仍大行其道。
究其原因：

- 垂直击中用户`痛点`：一个简单的工具app，可以更加直接、更加高效的满足用户需求。加水印就加水印，转文件就转文件，没有其他杂七乱八的干扰。
- 一人团队稳赚`不赔`： 工具app往往开发简单，广告订阅获利直接；不像大型系统，动辄数人数周，开发维护成本极大，且有可能直接暴毙，血本无归。
- 界面`清爽`深得你心：很多工具app，就是凭借着清爽、简约的UI偷了你的心，在这个繁闹的世界你已经很累了；譬如某东、某宝、某团之流，狠不得一个app中塞入所有，看着甚是心烦。

一个人、一台电脑、四处云游、记录生活、自由职业者，或许才是这个时代的答案。
