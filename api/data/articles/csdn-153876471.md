## **什么是树莓派🍓？**

树莓派（**Raspberry Pi**）是一款 **基于ARM架构的微型单板计算机** （Single Board Computer, SBC），由英国的 **Raspberry Pi 基金会** 开发，最初目标是用于**教育与编程入门**，但如今已广泛应用于**嵌入式开发、物联网、家庭自动化、机器人、媒体中心等领域**。

### 🧩 一、基本特点

*   **体积小巧**：约信用卡大小，但功能完整。
*   **价格低廉**：一百到几百元人民币即可入手。
*   **功耗低**：一般仅需 5V/2\~3A 电源即可运行。
*   **系统开放**：通常运行基于 Linux 的操作系统（如 Raspberry Pi OS、Ubuntu、Kali 等）。
*   **丰富接口**：提供 HDMI、USB、GPIO、摄像头接口、音频输出、网络接口等，可外接多种外设。

### ⚙️ 二、常见型号

| 型号                       | 处理器           | 内存       | 特点                   |
| ------------------------ | ------------- | -------- | -------------------- |
| **Raspberry Pi 4B**      | 四核 Cortex-A72 | 2GB\~8GB | 性能强，支持双显示器、千兆网       |
| **Raspberry Pi 3B+**     | 四核 Cortex-A53 | 1GB      | 内置 WiFi、蓝牙           |
| **Raspberry Pi Zero 2W** | 四核 Cortex-A53 | 512MB    | 体积超小，适合嵌入式项目         |
| **Raspberry Pi 5**       | 四核 Cortex-A76 | 4GB/8GB  | 性能翻倍，支持 PCIe、USB 3.0 |

### 💡 三、典型应用场景

1.  **学习编程**（Python、C、Scratch 等）
2.  **DIY 项目**（智能家居、自动浇花、远程监控）
3.  **多媒体中心**（Kodi、Plex 播放器）
4.  **小型服务器**（Web、NAS、VPN）
5.  **机器人与自动化控制**（利用 GPIO 控制电机、传感器）

### 🧠 四、主要优势

*   开放生态与丰富社区支持
*   软件资源众多（可直接使用 apt 安装常见软件）
*   支持多语言与多操作系统
*   成本低，适合学习与实验
